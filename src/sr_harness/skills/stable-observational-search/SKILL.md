# Execute stable candidate comparisons within the existing tool budget

Apply this skill only with an explicitly selected ObservationalEvaluator and the dedicated evaluate_observational_formula, submit_observational_formula and observational_statistics tools. Use the reviewed User Prompt's target, allowed variables, fixed split and objective; the generic agent does not inject a contract message. A distribution expression is an unnormalized density in the declared measure, not a prediction of each observation. Preserve successful fitted candidates while improving the process below.

1. Establish a baseline before structural search. For a density call evaluate_observational_formula(f="1.0", show_diagnostics=true); for regression evaluate a fitted constant using param syntax and fit=true. Record the declared train/validation loss, eligibility and sample counts. Read required engine syntax once. Use one compact observational_statistics call for training-domain checks; another histogram needs a stated unresolved question. The dedicated statistics tool labels frozen training data. Histograms from the ordinary statistics_analysis tool summarize the supplied live context and may include validation; do not relabel them as training-only evidence. Do not infer the number of components or a completeness cut from them.

2. Use the variables actually exposed by the tool. Contract metadata may be available to the evaluator but absent from formula/statistics inputs. Inspect result.exceptions as well as the outer success flag. If a metadata request fails, record the limitation and continue with supported inputs; do not retry the same absent columns or turn metadata into predictors. Do not claim group diagnostics that the interface cannot return.

3. Fix the coordinate scale before nonlinear fitting. On a declared finite support [L,U], substitute z=(x-(L+U)/2)/((U-L)/2) in trial expressions, expanding this substitution with the actual declared variable and support constants; z is not a new bare data symbol. This keeps the coordinate in [-1,1] without using validation statistics. Otherwise use training-only location/scale if accessible, or a physically declared scale; do not relabel pooled statistics as training statistics. A numerical coordinate substitution inside f(x) does not itself change the density measure. Retain the declared integration variable; changing the measure requires the appropriate Jacobian.

4. Fit identifiable shape parameters. Use param('name', value=...) with fit=true; reported fitted expressions, not initial guesses, are the candidates. In a normalized density, remove an overall amplitude or additive constant in its log-density: normalization cancels it. Keep preprocessing centers/scales fixed rather than introducing redundant adjustable offsets. Avoid multiple large terms that cancel inside exponentials. When a positive physical scale or positive component weight is required, a positive reparameterization such as exp(param(...)) can enforce it; do not impose positivity on coefficients that legitimately change sign. Negative individual coefficients do not alone prove the total density invalid.

5. Compare nearby structural changes. State a bounded search budget that fits the remaining calls. Starting from a fitted simple candidate, vary one structural feature at a time and retain the fitted incumbent before branching. Initialize shared parameters from the preceding fit where supported. New parameters should have modest, nondegenerate initial values in the scaled coordinate. Do not add several new components and scale parameters merely because a more detailed histogram suggests them. Alternative structures remain allowed when they answer an explicit diagnostic question; no family, component count or winning complexity is prescribed.

6. Inspect numerical and predictive results together. Record the full fitted expression, eligibility, parameter-fit status, train/validation declared loss, baseline gain, complexity and any integration diagnostic. A returned normalization Z need not equal one: the evaluator divides by it. Very large/small Z with compensating coefficients signals a need to rescale or reparameterize before increasing complexity, not proof of better science. Preserve the incumbent; test the equivalent stable expression and verify that losses agree. Reject nonfinite/negative total density or unstable integrals. If available, inspect quadrature refinement and positive-scale invariance; do not invent a check the tools did not perform.

7. Finish with an auditable candidate. Keep a compact ledger of successful and failed trials and return the exact fitted eligible expression with its declared metric. If train-only group folds are unavailable, call repeated development ranking model selection, not independent validation; group uncertainty and external confirmation remain unmeasured. Do not consume the remaining budget trying to reproduce an inaccessible diagnostic. Freeze the choice before any external assessment. A lower selection loss does not establish a unique physical law.

For regression, retain baseline-first execution, eligible inputs, fixed training-derived scaling, identifiable parameters, small structural comparisons and candidate preservation. Density normalization, density positivity and amplitude cancellation apply only to distribution tasks; an ordinary regression intercept or amplitude is generally estimable and must not be removed by this density-specific rule.
